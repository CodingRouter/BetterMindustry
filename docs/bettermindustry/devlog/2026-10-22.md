### 3. Web 调试器

新增独立 Java 17 模块：

```text
bettermindustry/orchestrator
```

启动：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Eclipse Adoptium\jdk-17.0.20.101-hotspot'
.\gradlew.bat -p bettermindustry/orchestrator run --no-daemon
```

浏览器地址：

```text
http://127.0.0.1:19090/
```

功能：

- 显示两个 Worker 的状态、PID、端口、运行时间和检查点。
- 显示真实子进程日志。
- 单独启动、停止和保存 Worker。
- 批量启动/停止。
- 发送任意服务端命令。
- 只绑定 `127.0.0.1`，不暴露局域网。

已验证：

- 页面返回 HTTP 200。
- `/api/overview` 返回两个 RUNNING Worker。
- 通过调试器停止 A 后，A 为 STOPPED，B 仍为 RUNNING。
- 通过调试器重启 A，A 自动加载检查点。
- 通过调试器发送 `status`，日志返回地图、波次、FPS 和玩家数。
- 两个 Worker 关闭时都保存了检查点，退出码均为 `0`。

### 4. Tick 与 Render 分离

新增架构决策：

```text
docs/bettermindustry/decisions/0004-tick-render-separation.md
```

原则：

- Game Tick Worker 是权威模拟，使用固定 Tick。
- Render Tick 使用现实帧率，只负责插值和画面表现。
- Render Tick 不能修改库存、位置、建筑或战斗结果。
- 多视口将来通过订阅多个 Game Tick 输出实现。
- 调试器当前只观察 Game Tick，渲染进程尚未实现。
