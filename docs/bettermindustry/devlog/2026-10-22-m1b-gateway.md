# 2026-10-22 M1B Gateway 原型日志

## 目标

在 M1A 双 Worker 底座之上，建立最小 Gateway 和多 WorldView 控制模型。

## 已完成

- 新增 `Gateway` 状态机。
- 使用 `FULL`、`SUMMARY`、`OFF` 三种视口模式。
- 保证同一时刻只有一个 Focus Sector。
- 禁止关闭 Focus Sector。
- 切换 Focus 时自动将该 Sector 恢复为 FULL。
- 新增 Gateway HTTP API。
- Render 协议升级为 `bettermindustry.render.v2`。
- 浏览器 WorldView 显示 FOCUS/OBSERVE。
- 浏览器支持切换主控和视口模式。
- SUMMARY 视口缩小地图，OFF 隐藏地图。
- Gateway 状态持久化到 `runtime/gateway.properties`。
- FULL/SUMMARY/OFF 分别控制 Worker 诊断与地图快照频率。
- Focus Sector 的 15 秒控制权租约。
- 浏览器稳定 Client ID、获取/续约/释放控制和自动续约。
- 每个 Client ID 独立的 Focus 和 WorldView 状态。
- 多 Session 视口需求合并为 Worker 有效采样策略。
- 控制租约按 Sector 独立管理。

## 验证

API 验证：

```text
初始：focus=sector-a, both=FULL
切换：focus=sector-b
设置：sector-a=SUMMARY, sector-b=FULL
```

Render v2：

```json
{
  "protocol": "bettermindustry.render.v2",
  "focusSectorId": "sector-b",
  "sectors": [
    {"id": "sector-a", "viewMode": "SUMMARY"},
    {"id": "sector-b", "viewMode": "FULL"}
  ]
}
```

浏览器验证：

- 两张地图图片都成功加载。
- `sector-b` 卡片带 FOCUS 状态和边框高亮。
- `sector-a` 显示 OBSERVE 和 SUMMARY。
- 页面 Render Tick 保持独立帧率。

状态恢复验证：

```text
设置：focus=sector-b, sector-a=OFF, sector-b=FULL
重启 Orchestrator
恢复：focus=sector-b, sector-a=OFF, sector-b=FULL
```

速率验证：

- A=OFF 后，即使持续访问 overview，`bmworld.png` 不再更新时间。
- B=FULL 在相同订阅期间持续更新地图快照。
- A 仍以 5 秒间隔执行低频状态诊断。

控制租约验证：

```text
client-a 获取 sector-a：200
client-b 同时获取 sector-a：409
client-a 续约：200
client-a 释放：200
client-b 重新获取：200
切换 Focus：旧租约清空
等待 16 秒：租约自动过期
浏览器等待 17 秒：自动续约仍有效
```

多 Session 验证：

```text
client-a：focus=sector-a, A=FULL, B=SUMMARY
client-b：focus=sector-b, A=OFF,  B=FULL

effective：A=FULL, B=FULL
```

- 两个 Client 可以同时分别持有 A/B 租约。
- B 尝试抢 A 的控制权返回 409。
- Render 帧按 `clientId` 返回各自的 Focus 和 ViewMode。
- 重启 Orchestrator 后两个 Session 状态完整恢复。

构建：

- `bettermindustry/protocol build` 通过。
- `bettermindustry/orchestrator build` 通过。
